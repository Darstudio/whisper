# MATEO

Aplicaci\u00f3n web sencilla para construir y exportar marcos l\u00f3gicos.

## Uso

1. Instale las dependencias necesarias:
   ```bash
   pip install flask fpdf2
   ```
2. Ejecute la aplicaci\u00f3n:
   ```bash
   python -m mateo_app.app
   ```
3. Abra `http://localhost:5000` en su navegador y comience a agregar objetivos, resultados, indicadores y actividades. Puede exportar su marco l\u00f3gico a PDF con el bot\u00f3n correspondiente.

La interfaz utiliza la paleta de colores de Deltagram Consultor\u00eda.
